# plumber

A geospatial pipeline framework: an ordered list of phase functions, run over a dataset by a swappable execution strategy.

## Language

**Checkpoint**:
A phase's output saved to disk because that phase's config entry opts in. Never saved automatically.
_Avoid_: Cache, snapshot, intermediate

**Partial run**:
A run that executes only a slice of the configured phases, chosen on the CLI rather than in the config.
_Avoid_: Resume, rerun, skip

**Input function**:
The user's own function that reads the pipeline's source data and returns it. Named in the config's `input:` block.
_Avoid_: Adapter, reader, loader, source

**Output function**:
The user's own function that writes the pipeline's final data to its destination. Named in the config's optional `output:` block.
_Avoid_: Adapter, writer, sink

**Adapter shim**:
A thin wrapper that gives an existing user function the shape of a phase. Hand-written once, then possibly generated by the AI skill.
_Avoid_: Adapter (alone), wrapper

**Check sample**:
A small, optional file shaped like the pipeline's input data. `check` runs the phases on it to catch bugs that only show up when phase code actually runs.
_Avoid_: Fixture, test data, sample data
