# plumber

A geospatial pipeline framework: an ordered list of phase functions, run over a dataset by a swappable execution strategy.

## Language

**Checkpoint**:
A phase's output saved to disk because that phase's config entry opts in. Never saved automatically.
_Avoid_: Cache, snapshot, intermediate

**Partial run**:
A run that executes only a slice of the configured phases, chosen on the CLI rather than in the config.
_Avoid_: Resume, rerun, skip

**Input function**:
Any function that reads the pipeline's source data and returns it, named in the config's `input:` block. It can be the user's own or a library function such as `geopandas:read_parquet`. Required.
_Avoid_: Adapter, reader, loader, source

**Output function**:
Any function that writes the pipeline's final data to its destination, named in the config's optional `output:` block. It can be the user's own or a library function.
_Avoid_: Adapter, writer, sink

**Adapter shim**:
A thin wrapper that gives an existing user function the shape of a phase. Hand-written once, then possibly generated by the AI skill.
_Avoid_: Adapter (alone), wrapper

**Check sample**:
A small, optional file shaped like the pipeline's input data. `check` runs the phases on it to catch bugs that only show up when phase code actually runs.
_Avoid_: Fixture, test data, sample data

**Run log**:
The one stream of log lines a run produces. Plumber's lines mark where each phase begins; the user's lines fall under the heading of the phase that was running.
_Avoid_: Output (clashes with **Output function**), trace

**Plumber log**:
Lines plumber itself writes about the run: the **Phase heading**, checkpoints saved, a run starting or ending.
_Avoid_: System log, framework log

**User log**:
Lines written by the user's own functions with ordinary Python logging. Plumber adds nothing to them.
_Avoid_: App log

**Phase heading**:
The **Plumber log** line that opens each phase's section in the **Run log**, so the log reads phase by phase. The input and output functions get one too (`input`, `output`), so their lines are never orphaned.
_Avoid_: Banner, title log, separator
